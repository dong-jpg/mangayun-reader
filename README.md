# MangaYun Reader

面向安卓 Chromium 系浏览器和 Tampermonkey 的漫画阅读增强脚本项目，首先适配 <https://mangayun.com>。

## 项目状态

当前已建立独立 Git 仓库并整理设计规格，正在进行规格审阅。尚未实现阅读器或下载器，也没有可安装的 `.user.js` 版本。

## 首版范围

- 日漫横向连续阅读，支持从左到右和从右到左的阅读顺序。
- 韩漫纵向连续阅读，默认适配屏幕宽度。
- 普通单页阅读，上、下、左、右点击区分别设置上一页、下一页或无操作。
- 手机触控、横竖屏适配、阅读进度记忆、附近页面预加载。
- 当前话、选定多话或整部漫画下载，按章节和页序编号，最终生成一个 ZIP。
- 手机低内存下载、有限重试、失败报告和可恢复的本地图片缓存。

## 设计规格

[手机优先设计](docs/superpowers/specs/2026-10-23-mobile-reader-design.md)

## 兼容性原则

不依赖桌面的保存文件选择器，不需要额外服务器。根据浏览器实际提供的存储和下载能力选择实现路径；不承诺任意大小的 ZIP、安卓后台持续运行或浏览器清除站点数据后的任务恢复。

仅处理用户正常可访问的资源，不绕过登录、付费或其他访问限制。
